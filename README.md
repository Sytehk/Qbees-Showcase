# Qbees

**Fashion e-commerce**

Qbees is an online fashion storefront for curated collections, product discovery, and checkout.

## Project scope

- Collection and product browsing
- Cart and checkout journeys
- Order and delivery workflows

**Technology:** Next.js and TypeScript, Supabase, Stripe.
